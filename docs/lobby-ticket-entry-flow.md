# 로비 문·티켓 이동과 매표소 안내

## 동작

- 로비의 실제 공연장 문 클릭은 `walkToEntrance()`로 연결된다. 기존 경로 탐색으로 중앙 계단을 올라 문 앞까지 걸은 뒤 zone을 바꾼다. 메뉴/하단 입장 아이콘은 기존 `changeZone()`을 호출하므로 문까지 걷지 않고 바로 들어간다.
- 로비 티켓에서 좌석 선택 시 좌석 ID를 보관한 채 문까지 걷는다. 도착 후 공연장 전경 3.5초 → 캐릭터 시점으로 전환/정착 2.5초 → 기존 예약·이동·착석 로직 순서로 진행한다. 이전 400ms 타이머가 전경을 건너뛰던 처리를 제거했다.
- 다른 바닥 클릭, 이동 키, ESC 등으로 이동을 취소하면 보관된 티켓 목적지도 취소된다. 아이콘 입장도 기존 보행 목적지를 취소한다. 문에 도착해 입장할 때만 선택된 좌석을 유지한다.

## 공간

- 시작 위치에서 보이는 바닥 화살표가 매표소 방향으로 이어지고 `매표소 · TICKETS` 바닥 글씨를 표시한다.
- 매표소 앞 대기 통로 양옆에 황동 기둥/붉은 가드레일을 배치했다. 가드레일은 shared furniture collision에도 포함해 통과할 수 없다.
- 매표소 앞 첫 카페 테이블을 (-9.8,24)에서 (-8.1,25.8)로 옮겼다. 렌더링/보행 장애물 위치가 같은 데이터를 쓴다.
- 양쪽 끝의 그림을 가리던 막힌 벽 반환부를 제거하고 같은 폭의 부분 아치를 앞뒤로 연장했다. 추가 아치는 외벽에서 일부 잘려 보일 수 있다.
- 아치 extrusion 깊이를 원점 양쪽으로 배분해 아치 중심면과 기존 원통 기둥 중심선을 맞췄다. 기존 높이 datum과 열 간격은 유지했다.
- 시작 미리보기는 변경된 실제 로비로 다시 렌더했고, 이전 화각 일치 규칙은 유지했다.

## 검증

- 타입 검사, Vite production build, git diff 형식 검사 통과.
- 실제 문 클릭 후 로비에서 3개 경유점으로 계단/문까지 걸어 공연장에 들어가는 것을 확인했다.
- 가드레일을 반영한 매표소 접근 경로와 매표소→공연장 문 경로를 확인했다. 대기열을 벗어나 계단으로 가는 경로가 생성됐다.
- Production build에서 실제 티켓 UI로 1층 22열 8번을 선택해 최종 착석을 확인했다. 100ms 간격 상태 기록에서 로비 보행 → 공연장 전경/정지 → 3.5초 뒤 캐릭터 시점/정지 → 2.5초 뒤 좌석 보행 → 착석 순서였다. 실행 오류 수집 결과는 비어 있었다.
- 로비 입장 아이콘은 출발 위치 (0,0,24)에서 걷기 경로 없이 약 158ms 뒤 공연장으로 바뀌었다. 서버/네트워크 조건에 따른 관측값으로 시간 보장은 아니다.
- 매표소 대기열, 테이블, 양쪽 끝 그림/아치와 기둥 중심 정렬을 화면에서 확인했다.

별도로 진행 중인 음원/플레이리스트/음원 테스트 변경에는 손대지 않았다. 검증 빌드는 audio-manifest 재생성 없이 Vite를 직접 실행했다. 이 변경은 아직 push/배포하지 않았다.
