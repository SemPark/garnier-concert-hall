# 황금빛 가을 음원 출처와 권리 확인

2026-11-16에 녹음별 Wikimedia Commons 설명과 출처를 대조했다. 비발디·그리그·브람스·멘델스존의 수록 작곡 원곡은 퍼블릭 도메인으로 분류했고, 아래 권리 표시는 개별 녹음을 기준으로 기록했다. Commons의 Original file에서 받은 Ogg Vorbis 녹음은 기존 오디오 경로에서 제공할 수 있도록 MP3 160 kbps로 변환했다. 서비스 파일은 `public/audio/`에 있다.

11곡의 MP3 재생시간 합계는 60분 1.603초다. 원본 게시본의 비발디 3곡에는 Commons에 명시된 −20센트 음높이 조정이 들어 있다.

## 확인 근거

- PDM-owner는 녹음의 퍼블릭 도메인 상태를 표시한다. Creative Commons의 Public Domain Mark 자체는 라이선스나 권리 포기가 아니다. 비발디 3곡은 Commons에 제3자 업로더와 Musopen 출처가 기록되어 있다. 해당 녹음에 대한 권리자 직접 선언이나 녹음·실연 권리의 허락 문서는 찾지 못했다. [Creative Commons Public Domain Mark](https://creativecommons.org/publicdomain/mark/1.0/) · [Musopen 비발디 출처](https://musopen.org/music/14910-the-four-seasons-op-8/) · [Musopen FAQ](https://musopen.org/faq/)
- 멘델스존 06·07은 Commons 표시와 별도로, Musopen이 자체 제작 녹음의 재사용을 명시한 공개 글과 Aaron Dunn이 등록한 녹음 목록에서 작품과 연주 출처를 대조했다. [Musopen 자체 녹음 공개](https://musopen.org/nl/blog/musopen-kickstarter-project-1-complete/) · [Musopen 원본 프로젝트 보관본](https://archive.org/details/musopen-lossless-dvd)
- CC0 05·08·09·10의 Commons 설명은 개별 녹음에 CC0를 적용한다. Musopen의 자체 녹음 공개 목록에도 브람스 교향곡 3번, 그리그의 페르 귄트, 멘델스존 이탈리아 교향곡이 포함된다. 04·11은 파일별 설명의 Musopen 위탁 녹음과 퍼블릭 도메인 선언을 확인했다. [Creative Commons CC0](https://creativecommons.org/publicdomain/zero/1.0/) · [Musopen 자체 녹음 공개](https://musopen.org/nl/blog/musopen-kickstarter-project-1-complete/)
- 공개 서비스 배포 전 각 원본 파일의 최신 권리 표시와 배포 지역에서의 작곡·녹음·실연 권리를 다시 확인한다. 비발디 01–03은 원권리자의 선언 또는 재배포 허락 확인이 남아 있다.
