# 타로 3장 시안 생성 기록

2026-11-13. 사용자 선택: ‘새 화풍의 태양·별·탑 3장 시안부터 확인하기’.

- 생성 경로: 내장 `image_gen.imagegen`만 사용. 외부 API·CLI·Higgsfield 호출 없음.
- 호출: 신규 카드 3회 + 별 상징 개수 수정 1회 + 탑 상징 개수 수정 1회 = 총 5회.
- 승인된 범위의 카드 종류는 태양·별·탑 3종뿐이다. 나머지 19장 생성 없음.
- 도구 설명에 별도 결제/크레딧 고지는 없었다. 계정별 과금액은 확인할 수 없으며 무료 또는 특정 비용이라고 단정하지 않는다.
- 1024×1536 PNG 원화를 보존하고, 앱용은 768×1152 WebP(quality 88)로 포맷 변환·리사이즈했다. 합성 테두리·번호·제목은 원화에 넣지 않았다.

## 생성·검수 결과

### 태양

첫 결과를 채택했다. 얼굴 있는 태양과 직선/곡선 광선, 백마와 아이, 붉은 깃발, 돌담, 해바라기 네 송이, 꽃관·붉은 깃털을 확인했다. 아이는 불투명한 아이보리 옷을 입은 고전 회화 표현이다. 글자·테두리 없음.

생성 원본: `exec-e5250057-506b-4637-a5f8-8f186b8137a0.png`.

### 별

태양 원화를 화풍 참조로 사용했다. 첫 결과는 작은 별이 6개여서 작은 팔각별 하나만 추가하도록 수정했다. 최종 결과는 큰 별 1개, 작은 별 7개(좌측 4/우측 3)를 확인했다. 두 물병, 물과 땅으로 나뉜 물줄기, 물 위 발과 땅 위 무릎, 나무와 새가 유지됐다.

원본의 비성적 고전 인체를 요청했지만 생성 결과는 성인 여성이 아이보리 옷을 입은 형태다. 시안의 화풍·구도 검토에서 이 차이도 함께 확인해야 한다.

채택한 수정본: `exec-8a3995da-91a3-4293-ba2d-a58364005419.png`.
미채택 최초본: `exec-dfb9c0d5-76d3-44ad-987e-5dd8e13a0cae.png`.

### 탑 — 세부 상징 보정 필요

태양 원화를 화풍 참조로 사용했다. 번개, 튕겨 나온 왕관, 불타는 석조 탑, 양쪽으로 떨어지는 성인 두 명, 바위산, 폭풍 구름이 잘 읽히는 최초 결과를 채택했다.

**불씨는 좌우 13개씩 총 26개로, 설계서의 22개 목표를 충족하지 않는다.** 불씨 네 개만 제거하도록 수정했으나 더 많은 불씨가 사라져 수정본은 채택하지 않았다. 출력당 최대 2회 지침에 따라 추가 생성하지 않았다. 카드 스타일 승인을 위한 시안이며, 정식 제작 전에 이 개수는 보정 대상이다.

## 사용 지시문

기본 지시문은 `sample-prompts.json`의 공통 및 카드별 지시문이다. 실제 호출에서 다음 내용을 구체화했다.

- 태양: 아이의 몸통과 엉덩이를 아이보리 튜닉/천으로 가리고 해바라기 네 송이를 명확히 지정. 2:3, 그림만, 모든 글자·테두리 제외.
- 별: 태양 파일을 **화풍만** 참조. 총 8개 별(큰 금색 1, 작은 아이보리 7)과 별처럼 보이는 추가 반짝이 금지. 최초 결과의 6개 작은 별을 그대로 두고 좌측 빈 하늘에 작은 팔각별 1개 추가하는 수정.
- 탑: 태양 파일을 **화풍만** 참조. 금빛 물방울 불씨를 좌우 11개씩 총 22개로 지정. 최초 결과의 26개에서 네 개만 제거하도록 수정했으나 정확도가 개선되지 않아 최초본 채택.
