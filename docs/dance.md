# PLEEE 댄스 모드

## 사용 방법

- 클래식·재즈 홀 하단 액션바에서 `춤추기`를 누르고 바닥을 찍거나 `현재 위치`를 선택한다. 다른 위치를 고르면 도착 후 시작한다. 고른 시야 방향은 춤 시작과 파트너 합류 때 유지된다. 좌석에 앉아 있을 때는 그 자리에서 시작한다.
- 춤추는 사람 발밑과 바로 앞 빈자리에 원이 보인다. 금빛으로 움직이는 빈 원을 누르면 해당 자리로 걸어가 파트너가 된다. 합류 후에도 양쪽 발밑 원이 보인다.
- 선택한 동작은 계속 반복되며 해당 아이콘은 금색으로 강조된다. 혼자 춤출 때는 다른 동작을 누르면 바로 시작한다. 2인 동작은 현재 주기를 마친 뒤 전환한다.
- 화살표가 달린 문 아이콘으로 춤을 끝낸다. 함께 춤추는 경우 두 사람 모두 1.6초 동안 손을 놓고 인사한다.
- 소품을 들고 있다면 먼저 소원/소품 동작을 마친다. 촛불은 춤 동안 감춘 뒤 복원한다.

## 구조와 설정

- `shared/dance.ts`: 서버 검증과 결정적인 공통 동작 계산. 두 손으로 연결된 채 가까워지며 팔을 펼치고 멀어지며 좁힌다. 점프는 두 손을 잡고 함께 돌면서 버튼을 누른 사람만 뛴다. 단독 회전은 0.58초 동안 가까워졌다 멀어진 뒤 손을 놓고 0.418초 동안 돌며, 끝나면 다시 잡는다. 손잡고 도는 점프는 한 주기 1.45초다. 기존 음원에 BPM/박자 메타데이터가 없어 기본 속도를 사용한다.
- 같은 방과 층의 빈 원에 서 있는 한 명이 합류할 수 있다. 서버가 빈 원 반경 0.43m와 회전 공간을 확인한다.
- 회전 중심 주변 1.2m 원과 바닥 높이, 주변 관객을 검증한다. 객석 가구는 원형 테이블과 의자 방향을 반영한 실제 폭에 가깝게 판정한다. 두 사람의 발 위치와 진입 경로에는 일반 이동 판정을 적용한다.
- `Visitor.dance`에 상대 ID·역할·공통 시작 시각·중심·각도·종료 시각을 저장한다. 클라이언트는 서버에 관절이나 프레임별 춤 위치를 보내지 않는다.
- `VenueRoom.ts`의 기존 WebSocket attachment와 snapshot/delta, 공용 alarm에 연결했다. 단절 시 남은 상대도 종료한다. 로비·좌석·층 이동·열차로 전환하면 춤 상태를 해제한다.
- `DancePose.ts`는 사람의 기존 팔과 몸을 사용한다. `Ghosts.ts`는 기존 불투명 인스턴스의 팔 방향/길이와 몸 기울기 속성만 바꾼다. 꼬마 선장 춤에서 사람 아바타의 상완과 전완을 각각 움직이고 손목을 회전한다. 기본 팔과 같은 재질·두께의 연속된 소매를 팔꿈치에 맞춰 굽힌다. 다른 동작에서는 기본 소매로 돌아간다.
- 금빛 음표는 기존 `EmoteLayer` 아틀라스/포인트 배치에 포함한다. 다른 리액션이 없을 때 음표 표시용 배치 최대 1 draw call이 추가된다.
- 단독 감상(`LocalConcert`/`Presence`)도 혼자 춤추기와 종료를 지원한다.

## 변경 파일

- 공유: `shared/dance.ts`, `shared/protocol.ts`, `shared/venue.ts`
- 서버/통신: `server/VenueRoom.ts`, `src/network/Presence.ts`, `src/network/LocalConcert.ts`
- 장면/캐릭터: `src/World.ts`, `src/scene/DancePose.ts`, `src/scene/Ghosts.ts`, `src/character/Avatar.ts`, `src/character/EmoteLayer.ts`, `src/character/villager.ts`
- UI: `src/DanceControls.tsx`, `src/main.tsx`, `src/style.css`
- 테스트/문서: `tests/dance.test.ts`, `tests/dance-integration.ts`, 이 문서, `진행상황.md`
- 기존 인사·쉿 동작의 팔/머리 겹침 회귀도 수정했다. 앞쪽으로 손을 들어 올리고 입에 접근하도록 보간한다.
- 이전 입장/뒤쪽 이동 카메라 변경과 기타 미커밋 파일은 보존했다.

- 혼자 춤추는 중 ‘유령과 춤추기’를 누르면 빈 원에 NPC가 합류한다. 서버가 공간을 확인하며, 관전자는 저장된 파트너 상태에서 같은 유령과 안무를 그린다. 단독 감상에서도 사용할 수 있다.
- 2인 메뉴에서 꼬마 선장, BAD, 플로스, 어깨 흔들기를 고르면 둘이 손을 놓고 같은 방향으로 나란히 서서 같은 박자로 반복한다. 사람 파트너와 유령 파트너에 같은 규칙을 사용한다. 춤 끝내기를 누르면 두 사람은 손을 놓고 조금 물러나 서로를 향해 돌아선 뒤 고개를 숙이고 마친다.

## 검증

- `npm run check`, `npm test` 177개, `npm run build` 통과. 빌드에는 기존 대형 번들 경고가 남아 있다.
- `CONCERT_TEST_URL=http://127.0.0.1:8788 node --import tsx tests/dance-integration.ts`: 클래식/재즈 각 2클라이언트의 시작·빈 원 직접 합류·동일 시각 포즈와 회전·점프·이동 잠금·양쪽 종료·연결 해제 통과.

- 이전 390×844 터치 에뮬레이션에서 시작/종료와 상대 종료를 확인했다. 현재 시작·종료 아이콘의 터치 영역은 각각 44×44px이다. 단독 감상용 Presence에서도 시작/종료 타이머를 확인했다. 음악 재생 상태 유지.
- 재즈 홀 뒤쪽, balanced, 렌더 버퍼 1289×899, 활성 탭 비교: 정지 744~745 calls / 춤 745 calls. FPS는 정지 1~10 / 춤 1~29로 데스크톱 환경 변동이 커 성능 영향 판정에 사용할 수 없다. 개발 서버 재시작·백그라운드 탭이 섞인 이전 표본은 제외했다.
- iPhone 13 Pro 실기기 FPS·발열·Safari 터치·음악 실청취, 높은 지연/패킷 손실 환경은 추가 확인이 필요하다. 데스크톱 결과를 실기기 결과로 간주하지 않는다.
- 배포, GitHub 푸시, 유료 API/크레딧 사용 없음.

- 꼬마 선장은 양팔을 어깨 너비 그대로 정면과 뒤로 수평으로 뻗고 각 역할마다 위아래로 두 번 튕긴다. 수영 동작으로 넘어갈 때는 팔을 편 채 어깨 방향을 돌린다. 두 팔은 반 바퀴 차이로 기존과 반대 방향으로 한 바퀴를 돌고(6.75~8.02초), 주먹을 0.275초에 한 바퀴 굴린 뒤 첫 동작으로 이어진다. 전체 주기는 8.655초다.
