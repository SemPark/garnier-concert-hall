음악당으로 돌아가기

PLEEE 방문·재생 통계 안내

음악당의 방문과 음악 재생이 얼마나 이어지는지 파악하기 위해 Google Analytics 4(GA4) 통계에 참여할 수 있어요. 참여는 선택이고 기본값은 꺼짐입니다. 참여하지 않아도 음악당과 음악을 이용할 수 있어요.

Google Analytics에 보내는 정보

동의한 이후에만 페이지 보기, 음악 재생 시작, 누적 180초 재생 도달 여부를 Google LLC의 Google Analytics에 전송해요. PLEEE는 이 이벤트에 캐릭터 이름, 곡명, 주소의 쿼리 문자열을 넣지 않아요. Google Analytics는 통계와 기본 서비스 제공을 위해 브라우저·기기 정보, 방문과 세션을 구분하는 쿠키 식별자, IP 주소에서 파악한 대략적인 지역 정보를 처리할 수 있어요. Google은 IP 주소를 스팸 방지와 대략적인 지역 파악 등에 사용한 뒤 원본을 버린다고 안내합니다. PLEEE는 이 통계를 광고 맞춤설정에 사용하지 않아요. Google이 파트너 사이트의 데이터를 사용하는 방법을 참고하세요.

Google은 여러 국가의 데이터 센터를 운영하며, 이 서비스에 사용되는 정보는 이용자가 있는 국가 밖에서 처리될 수 있어요. Google의 국제 데이터 처리 안내를 참고하세요.

Google Analytics 보관 기간

PLEEE의 Google Analytics 설정에서 이벤트 단위 데이터는 2개월, 사용자 단위 데이터는 14개월 보관합니다. 새 사용자 활동이 있으면 사용자 단위 데이터의 보관 기간이 다시 시작돼요. 이 기간은 일반 집계 보고서에는 적용되지 않아요.

선택 변경하기

음악당 오른쪽 메뉴의 설정 → 방문·재생 통계에서 언제든 끌 수 있어요. 끄면 이후 GA4 전송이 중단됩니다. 이미 전송된 데이터는 이 설정을 끈다고 삭제되지 않아요. 동의 선택은 현재 브라우저에 저장됩니다. 저장된 통계 쿠키는 브라우저의 사이트 데이터 설정에서 직접 삭제할 수 있어요.

별도로 사용하는 Cloudflare 웹 통계

PLEEE는 방문 및 페이지 로딩 성능을 집계하는 Cloudflare Web Analytics도 사용합니다. Cloudflare에 따르면 이 웹 통계는 쿠키나 주소의 쿼리 문자열을 수집에 사용하지 않습니다. 위 설정은 Google Analytics만 끄며, Cloudflare 웹 통계에는 적용되지 않아요. Cloudflare 웹 통계 안내
