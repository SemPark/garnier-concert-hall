# BigQuery 샌드박스의 일별 이벤트 대조

선택 사항입니다. 대시보드는 BigQuery를 호출하지 않습니다. 이미 GA4 일별 내보내기가 있는 결제 계정 미연결 샌드박스에서만 사용할 수 있는 읽기 전용 SQL 예시를 제공합니다. 사용자가 결제 계정이나 신용카드 등록 요청을 받거나 현재 프로젝트의 결제 상태와 무료 잔여 처리량을 확인할 수 없으면 조회를 중단하고 기존 GA4 집계 또는 CSV 가져오기를 사용하세요.

1. SQL 파일에서 `YOUR_PROJECT.analytics_YOUR_PROPERTY`를 자신의 기존 일별 데이터셋으로 교체하세요. 데이터 위치가 프로젝트의 쿼리 위치와 일치하는지 확인합니다.
2. 문자열 매개변수 `start_suffix`와 `end_suffix`에 같은 날짜(예: `20261119`)를 지정합니다. 일별 테이블의 날짜는 GA4 속성 시간대를 따릅니다.
3. 실행 버튼을 누르기 전에 프로젝트의 결제 계정 미연결 상태, 샌드박스 잔여 처리량, 쿼리 검사기의 예상 처리 바이트를 확인하세요. 추정할 수 없거나 잔여량을 다른 작업과 공유해 보장할 수 없으면 중단합니다.
4. 이 예시의 자체 조회 상한은 한 번에 10 MiB(10,485,760바이트)입니다. 예상 처리량이 이 상한을 넘거나, 잔여량이 이 상한보다 적으면 실행하지 않습니다. 실행할 때도 쿼리 설정에서 **maximum bytes billed**에 이 상한을 지정할 수 있을 때만 진행합니다. 이 상한은 서비스가 무료로 제공하는 할당량을 뜻하지 않습니다.
5. 결과의 세 열은 날짜, 이벤트 이름, 해당 이벤트 건수입니다. 과거 좌석 위치·개별 방문 경로·체류 시간은 제공하지 않습니다. GA4 일별 전체 이벤트 수와 범위가 달라 이 파일을 대시보드의 GA4 일별 총계 CSV로 가져오면 안 됩니다. 장기 보관은 대시보드의 GA4·Search Console 일별 CSV/SQLite 경로를 사용하세요.

이 SQL은 이벤트 이름과 날짜만 조회하며 원시 방문자 식별자, 위치, 이벤트 매개변수를 요청하지 않습니다. 저장 테이블·예약 작업·스트리밍 내보내기 설정은 필요하지 않습니다.
